The JSON files in this directory are adaptations of the above TEI dictionaries.
Changes: extracted headwords/forms and translation equivalents, normalized lookup
keys, merged duplicate equivalents, removed non-lookup metadata, and serialized
the results as JSON. These adapted dictionary data are distributed under the same
CC BY-SA 3.0 license. The application source code is a separate work.

Per-file source URLs, checksums and entry counts are recorded in sources.json.
Reproducible preparation script: tool/prepare_dictionaries.py.
